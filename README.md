## Funcionalidade: Calculadora de IMC

O frontend possui uma calculadora de IMC disponível para usuários autenticados em
`/imc`. A tela valida peso e altura, calcula o índice, exibe a classificação e
apresenta um aviso de que o resultado não substitui uma avaliação profissional.

Para executar o frontend:

```bash
cd frontend
npm install
npm start
```
